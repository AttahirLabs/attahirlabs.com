# Vector redesign — September 22, 2026

Implements the approved original Vector homepage, richer individual app pages with actual app logos, and purposeful motion across marketing, editorial, and utility pages.

## Implementation

- Layered CSS blue-glass homepage; numbered product rows; separate unreleased-app band.
- Six branded product pages with original logos, distinct optimized decorative scenes, benefit-led copy, native links, and direct-control walkthroughs.
- Existing live-app pricing, features, FAQ schema, listing screenshots, acquisition campaigns, free tools, and blog content remain source-backed.
- Unreleased interface previews are explicitly illustrative. Notification forms use the existing PR #36 handler with a separate preview D1 database.
- Blog cards, reading progress, active TOC (where present), mobile menu, focus feedback, reduced motion, and no-JavaScript fallbacks.
- Shared enhancement adds about 28 KB CSS and 5.5 KB JS uncompressed; no client framework. Six decorative WebP images total about 408 KB. Images use original generated assets; original app logos were resized without redesign.

## Editing

Public product content lives in `data/public-apps.json`. Components live in `tools/design-components.mjs`; unreleased-page composition and theme injection live in `tools/sync-vector-design.mjs`. Homepage editorial structure is authored in `index.html` with catalog-generated product rows.

Run after content changes or adding a page:

```sh
node tools/sync-product-pages.mjs
node tools/sync-vector-design.mjs
node tests/run-all-tests.js
git diff --check
```

The consistency tests reject generated drift. New blog pages must receive the shared design assets via the vector sync before publication.
