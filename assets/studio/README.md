# Navy Studio visual assets

Direction B approved October 3, 2026. The shared theme uses navy, ivory, teal, warm retail photography, and readable HTML interface concepts.

- `shelflife-stage.webp`: generated navy glass still life with botanical details, an amber bottle and packaging. Decorative backdrop; 1400 × 933.
- `commerce-stage.webp`: generated navy glass and packaging still life. Decorative backdrop; 1400 × 933.
- `fashion-editorial.webp`: generated boutique fashion portrait for the fictional ALDER storefront concept. 900 × 1350.
- `coffee-editorial.webp`: generated unbranded coffee product photograph for the fictional NORTH storefront concept. 900 × 600.
- `attahirlabs-mark-light.svg`: ivory version of the existing Attahir Labs mark, with its teal tip.

The hero interfaces are selectable HTML, not text embedded in generated images. Actual published app screenshots remain in the screenshots and workflow sections. Storefront examples are labeled as concepts.

The homepage fallback posters in `assets/commerce/` were captured from the running six-business WebGL elevator with its café selected; they use the same animation and lighting as the live hero.

Manrope is self-hosted in `assets/fonts/`; its OFL license is included alongside the font.
