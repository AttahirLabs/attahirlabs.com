# Navy district homepage assets

Promoted unchanged from the selected AttahirLabs Concept 1 homepage on October 29,
2026. The source was the preserved local commerce-world prototype; no new
image or video generation was performed for this release.

The three WebP illustrations are 1536 by 1024 pixels and were generated with the
built-in OpenAI image generation tool on October 19, 2026. They are illustrative
miniature business scenes. The cafe MP4, poster and character credits are
unchanged copies of the previously rendered 12-second Unreal cafe detail.

The approved scene runtime was promoted byte for byte. The approved homepage CSS
retains the selected layout, with appended rules for current app-listing links
and an October 29 typography pass that enlarges reading text, actions, labels
and illustrative interfaces. The subsequent homepage cleanup removes auxiliary
scene labels, controls and the café viewer. Decorative drift now settles after
one four-second pass because the pause control was removed. All
public paths are under `assets/navy-district/`; developer prototypes, Unreal
sources and private review material remain outside the public static artifact.

Public attribution is in `scene-credits.txt` and `cafe-credits.txt`.
