What this US import duty calculator does

This calculator evaluates exact caller-supplied HTSUS, MFN, customs-value, and Chapter 99 inputs against signed, reviewed Release 3 authority. It returns a supported total rate, estimated duty, line-item authority evidence, and an estimated subtotal only when every required fact matches active coverage.

The estimated subtotal is customs value plus optional shipping and insurance plus estimated duty. Shipping and insurance remain outside the customs value in this model. Taxes, brokerage, carrier and processing fees, and unsupported tariff programs are excluded.

Quick answer

Use it only when you already have the entry’s exact U.S. filing inputs. It does not classify goods, select Chapter 99 headings, establish customs value, apply unsupported programs, or make a legal filing determination.

Fail-closed coverage

Incomplete, unsupported, expired, or non-matching inputs return an indeterminate response with no rate, duty, or subtotal. Canada and non-ad-valorem programs such as polysilicon minimum prices are intentionally outside this Release 3 coverage.

Signed reviewed authority

Every calculated response identifies its ruleset, signed release record, evidence window, active coverage slices, and source-backed line items so the result can be traced to the exact authority used.
